# 검증 게이트 — 스크린샷 대조 + 값 측정 (둘 다 필수)

산출 코드가 Figma와 맞는지 검증한다. 게이트는 **3개 축 전부 통과해야** 한다:

1. **스크린샷 대조** — 구조·정렬·배치를 잡는다.
2. **문구 전수표** — 텍스트 노드 전부를 1:1 대조한다.
3. **값 측정** — 색·두께·radius·간격 등 정밀 수치를 대조한다.

> 왜 셋 다인가: 눈 대조는 1~2px급 radius·gap·weight·투명도·몇 글자 문구 차이를 **구조적으로 못 잡는다**. 이슈 #46(12건)·#47(9건)·#49(4건)·#40 전부 "스크린샷 게이트만 통과시킨" 뒤 사후 실측에서 발각됐다. 값 측정을 "선택"으로 두면 어떤 이유(도구 장애·시간)로든 생략된다 — 필수다.

## 축 1 — 스크린샷 ↔ Figma 대조

기대값이 필요 없고 전 페이지에 동일하게 쓰인다.

1. **Figma 샷** — `get_screenshot`으로 대상 노드(프레임 전체 + 변형별 하위 노드)를 찍는다.
2. **구현 샷** — dev 서버를 띄우고(`pnpm --filter web dev` → localhost:3000) 재사용 헬퍼로 찍는다:
   ```
   node apps/web/scripts/figma-shot.mjs --url http://localhost:3000/<route> --out <tmp>.png --full
   node apps/web/scripts/figma-shot.mjs --url .../<route> --selector "text=정우성" --closest article   # 카드 1장
   ```
   - `--out` 미지정 시 OS temp로 저장(레포 밖). **PNG는 일회용 — 찍고 대조 후 삭제, 절대 커밋 X**(`.gitignore`로도 막아둠).
3. **눈으로 대조** — 두 이미지를 비교: 전체 구조(컬럼·순서) → 정렬(가운데/양끝) → 표시 텍스트(라벨·버튼·수치 글자 그대로) 순.

### 실행 함정 (이 프로젝트 특유 — 매번 재발함)

- **Bash 툴엔 `node`가 PATH에 없다**(Git Bash). 헬퍼는 **PowerShell 툴로** 실행.
- 헬퍼는 **`apps/web` 안**에 있어야 `@playwright/test` 모듈이 해석된다(레포 루트/`/tmp`에서 import 시 모듈 못 찾음).
- **dev 서버 먼저** 떠 있어야 함. 안 떠 있으면 `ERR_CONNECTION_REFUSED`.
- **한글/중복 텍스트 selector**: `getByText("정우성 사정사")`는 이름+배지가 분리돼 타임아웃 → 부분매칭(`text=정우성`), 카드 단위는 `--closest article`. 같은 문자열이 사이드바·카드에 중복되면 스코프를 좁힌다.

## 축 2 — 문구 전수표 (필수)

Figma **텍스트 노드 전부**(placeholder·버튼 라벨·배지·수치 표기·변형별 문구 포함)를 표로 뽑아 구현 문자열과 1:1 대조한다. **불일치 0이어야 통과.**

| 노드 | Figma 문자열 | 구현 문자열 | 판정 |
|------|-------------|------------|------|

- 주요 요소만 샘플링하지 말 것 — #47에서 placeholder·버튼 라벨 같은 잔가지가 샘플링에서 전부 샜다.
- 구조 다른 변형(모바일 프레임 등)은 변형별로 문구가 다를 수 있다 → 각 변형 프레임의 텍스트 노드를 따로 뽑는다.

## 축 3 — 값 측정 (필수)

**핵심 요소(카드·CTA·배지·입력·레이아웃 컨테이너)는 `get_design_context` 값 ↔ `getComputedStyle`을 1:1 대조한다.** "폰트 미로드 의심 시에만"이 아니다 — 항상 수행한다. `getComputedStyle`은 항상 px 반환 → rem로 작성해도 비교는 px.

측정 대상 축(전부):
- **색** — text·bg·border hex (ink vs ink-2 한 톤 차이가 주 미스)
- **폰트** — family, **weight**(semibold vs medium), size, 투명도(opacity)
- **radius** — 카드·버튼·배지 (22 vs 16/20px 사례)
- **간격** — 레이아웃 컨테이너의 **gap·padding·margin은 폰트와 무관하게 항상 측정**(#49: 스크린샷으로는 2~4px gap 차이가 절대 안 보임)
- **아이콘** — 종류(변형)·크기·색

```ts
const s = await el.evaluate((n) => {
  const c = getComputedStyle(n);
  return { fontFamily: c.fontFamily, color: c.color, backgroundColor: c.backgroundColor,
           fontSize: c.fontSize, padding: c.padding, gap: c.gap, borderRadius: c.borderRadius };
});
```
기대값은 `get_design_context` 값(페이지마다 다름 — 재사용 불가, 그래서 범용 스크립트는 만들지 않는다). 색은 hex 정규화, 길이는 ±1px 허용. **대조 결과는 요소별로 "노드 근거(node id + design_context 값) ↔ 측정값" 형태로 기록**한다 — 근거 없는 "일치" 선언은 무효.

## 도구 장애 시 절차 (get_design_context 불능)

transport drop·타임아웃으로 `get_design_context`가 죽어도 **"스크린샷 + 토큰 근사"로 폴백해 정밀값을 채우는 것은 금지**다(#46: 그렇게 진행한 12건 전부 오답).

1. **구현 범위 축소** — 구조·문구·배치(스크린샷·metadata로 확인 가능한 범위)까지만 구현한다.
2. **보류 플래그** — 색·크기·radius·weight·간격 등 정밀값이 걸린 스타일은 코드 근처나 작업 로그에 `⚠️ 실측 보류` 플래그를 남긴다.
3. **완료 선언 금지** — 보류 플래그가 하나라도 남아 있으면 "게이트 통과/완료"를 선언할 수 없다. 커밋은 가능하되 **PR 전 재측정 필수**.
4. **능동 재시도** — 도구 복구는 조용히 일어난다(알림 없음). PR 직전 체크리스트에서 `get_design_context`를 능동적으로 재시도해 보류 항목을 실측·해소한다.

## 검증자 분리 + PR 직전 재조회

- **만든 사람이 검증하지 않는다.** 빌더가 구현했으면 게이트는 별도 패스(에이전트/세션)가 **"수정 금지, 탐지만"** 모드로 실행한다. 자기가 쓴 문구·스타일은 정답처럼 보인다(#47: 빌더 자체 게이트 1건 vs 분리 감사 9건).
- **PR/머지 직전 Figma 재조회** — 작업 중 프레임이 바뀔 수 있다(#47: PC 프레임이 구현 후 업데이트됨). 대상 프레임을 다시 조회해 드리프트가 있으면 반영 여부를 사용자와 확인한다.

## 변형·구조 누락 방지 (이게 진짜 사각지대)

- **레이아웃/구조 불일치**(가로↔세로, 컬럼, 순서)는 값 측정으로 안 잡힌다 → 위 스크린샷 대조로 막는다.
- **색·폰트두께·배경 미세 오류**(ink vs ink-2, semibold vs medium, 없는 배경 발명)는 스크린샷으로 거의 안 보인다 → 각 노드 `get_design_context`의 hex·폰트명·fill을 **코드 토큰과 직접 대조**(figma-mapping §0). metadata로 추측한 섹션이 주범.
- **측정/대조 안 한 노드 = 검증 안 된 것.** 구조가 다른 변형(추천 카드 vs 일반 카드 등)은 **각각 `get_design_context`로 조회**하고 각각 샷을 찍어 대조. "일반 카드 + 배지 = 추천 카드"식 추측 스펙 금지.
  > 실제 사례: 추천 카드를 일반 카드 재사용으로 가정 → 가로형 구조를 통째로 틀림. 일반 카드만 보고 "통과"로 끝내서 못 걸렀음.

## 판정·재시도

| 결과 | 처리 |
|------|------|
| 3축(스크린샷·문구 전수표·값 측정) 전부 통과 + 보류 플래그 0 | 통과 |
| 불일치 | **해당 부분만** 지정해 재생성(전체 재생성 X) |
| 2회 초과 잔존 | 중단 → 불일치 리포트를 사용자에게 제시 |

- 색 불일치 → 토큰 미스매핑, `figma-mapping.md §1`로 회귀.
- 정렬/구조 불일치 → auto-layout 매핑(`§4` 정렬축) 재확인.
- 텍스트 불일치 → `§7`(Figma 문자열 그대로) 위반.

통과 못한 채로 "완료" 처리하지 않는다. PNG는 대조 끝나면 삭제한다.
