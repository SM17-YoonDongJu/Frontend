## 설명

세션 전수조사에서 반복되는 작업 흐름을 스킬로 표준화한다. 그리고 팀이 함께 보는 산출물을 Notion 한곳에 모아 관리한다.

개발하다 미룬 "보류 항목"과 백엔드와 맞춰야 할 "API 협의 사항"을 각각 Notion 표로 기록해 팀이 한눈에 보게 한다. 또 사람이 보는 PR·이슈·이 두 문서는 "AI가 쓴 티" 검사를 통과하지 못하면 올리지 못하게 훅으로 막는다.

이슈·API명세 작성 스킬(`issue-craft`·`api-spec-notion`)은 이미 추가했다. 이 이슈는 나머지(Notion 표 구축, `notion-log` 스킬, AI 문체 검사 훅)까지 묶어 추적한다.

## 작업 목록

### 1. 이슈·API명세 작성 스킬 (완료)
- [x] `issue-craft` — GitHub 이슈를 팀 양식에 맞춰 쓰도록 표준화한 스킬. 제목 태그·라벨·담당자를 자동으로 맞추고, 만들기 전에 비슷한 기존 이슈를 먼저 보게 해 양식이 어긋나지 않게 한다
- [x] `api-spec-notion` — 화면에 필요한데 API 명세에 없는 엔드포인트를 팀 형식 초안으로 정리해 백엔드에 요청하는 스킬. 경로·필드를 추측으로 지어내지 못하게 막는다

### 2. 보류 항목을 Notion에 기록
개발 중 "지금은 안 하고 미룬 일"을 팀이 한곳에서 볼 수 있게 표로 정리한다. 나중에 "이거 왜 안 했지?"가 안 생기게 한다.
- [ ] "프론트엔드 개발중 생긴 보류 문서" 페이지에 보류 항목 표(데이터베이스) 만들기
  - 각 항목에 담을 것: 무엇을 미뤘는지 · 유형(스킬/기능/리팩터 등) · 진행 상태 · 미룬 이유 · 언제 다시 할지 · 관련 PR·이슈 · 우선순위
  - 상태별로 칸반처럼 보는 보드뷰 추가
- [ ] 지금 코드 메모에 흩어져 있는 보류 항목들을 이 표로 옮기고, 앞으로는 이 표를 기준으로 관리

### 3. 백엔드 API 협의 사항을 Notion에 기록
백엔드와 맞춰야 할 API 이야기를 "언제 · 어느 PR · 무슨 내용"으로 한눈에 보이게 표로 정리한다.
- [ ] "tempr" 페이지 이름을 "백엔드 API 협의 로그"로 바꾸고 협의 항목 표(데이터베이스) 만들기
  - 각 항목에 담을 것: 협의 내용 · 날짜 · 관련 PR·이슈 · 대상 엔드포인트 · 도메인 · 진행 상태(협의 필요 → 확정 → 반영 완료)
- [ ] 지금 그 페이지에 글로만 적혀 있는 채팅 API(#48) 논의를 항목 3개로 나눠 표에 넣기
  - 목록 응답에 필요한 필드 추가 요청
  - 새 에러코드(`CLOSED`)를 전역 목록에 등록 요청
  - `senderId` 타입(문자열 vs 숫자) 확정 요청

### 4. Notion 기록용 새 스킬 `notion-log`
위 두 표에 "언제·어떻게 기록할지" 규칙을 담은 스킬을 만든다. 사람이 매번 형식을 고민하지 않게 한다.
- [ ] 보류가 생기면 보류 표에, 백엔드와 협의할 게 생기면 협의 표에 한 줄 추가하는 규칙 정의
- [ ] `api-spec-notion`은 명세 초안만 만들고, 협의 표에 기록하는 일은 이 스킬이 맡도록 연결

### 5. "AI 문체 검사" 통과해야만 게시되게 하는 훅
PR·이슈·위 두 Notion 문서가 "AI가 쓴 티" 검사를 통과하지 못하면 아예 못 올라가게 막는다.
- [ ] (선행 확인) 게시를 가로채는 훅이 Notion·GitHub 명령까지 실제로 막을 수 있는지 먼저 검증한다. 안 되면 방식을 다시 설계한다
- [ ] GitHub 이슈·PR 생성·수정과 위 두 Notion 문서 게시를 대상으로, "검사 통과 기록"이 없으면 게시를 막는 훅 추가
- [ ] 검사를 통과한 본문만 통과 기록을 남기고, 그 본문 그대로 올릴 때만 게시가 열리게 한다
- [ ] `issue-craft`·`notion-log`·PR 작성 절차에서 AI 문체 검사를 돌리고 통과 기록을 남기도록 연결

### 6. 문서·설정 정리
- [ ] CLAUDE.md에 "사람이 보는 산출물(PR·이슈·Notion 로그)은 AI 문체 검사를 통과한 뒤 게시" 규칙과 변경 이력 추가
- [ ] 검사 통과 기록 파일을 버전관리에서 제외(`.gitignore`)
