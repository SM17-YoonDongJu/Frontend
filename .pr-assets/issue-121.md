## 설명

손해사정 요청 퍼널에 손해사정사에게 전할 말을 자유롭게 적는 단계를 추가한다. 보험금·보험 다음, 서류 업로드 앞에 들어가 총 6단계에서 7단계가 된다. 질문 입력은 선택이다. 적어둔 내용은 분석 요청에 담겨 검수하는 손해사정사에게 전달된다.

이 질문을 파트너 검수 화면과 고객 리포트 상세에서 보여주는 일은 범위 밖이다(별도 이슈).

## 작업 내용

### 1. 전할 말 단계 (5/7)

- [ ] 제목 "손해사정사에게 전할 말이 있나요?"
- [ ] 안내 문구 — 시안이 뷰포트별로 다르므로 각각 적용
  - PC: "궁금한 점이나 특이사항을 자유롭게 적어주세요. 검수하는 손해사정사가 함께 확인합니다. (선택)"
  - 모바일: "궁금한 점이나 특이사항을 자유롭게 적어주세요. 검수하는 손해사정사가 함께 확인해요." + 필드 라벨 "궁금한 점 · 특이사항 (선택)"
- [ ] 500자까지 자유 입력, 글자수 실시간 표시
- [ ] 예시 안내 "이런 걸 많이 물어봐요" — 칩 4종 표시
  - "제안받은 보험금이 적정한지 궁금해요" · "과실 비율에 이의가 있어요" · "이미 합의했는데 추가 청구가 가능할까요?" · "어떤 서류가 더 필요한가요?"
  - 눌러도 동작하지 않는 예시 안내다. 선택·추가 기능 없음
  - PC 2열, 모바일 1열
- [ ] 하단 안내 "지금 적지 않아도 분석 요청 후 채팅으로 언제든 전할 수 있어요."
- [ ] 입력하지 않아도 다음 단계로 진행

### 2. 공용 `Textarea` 글자수 표시 옵션 추가

- [ ] 글자수를 입력 박스 안 우측 하단에 표시하는 옵션 추가
  - 현재는 박스 밖 좌측에 `0/500자` 형식으로만 표시 가능해 시안과 어긋난다
  - 기존 사용처(검수 의견·활동 분야) 표시는 그대로 유지

### 3. 단계 삽입에 따른 퍼널 정리

- [ ] 단계 정의 배열에 "전할 말" 삽입 — 서류 업로드 6, 확인 7로 이동
- [ ] 위치를 이름에 박은 검증 스키마·컴포넌트 리넘버
  - `step5DocumentSchema` → `step6DocumentSchema`, `step6ConsentSchema` → `step7ConsentSchema`
  - `Step5Documents` → `Step6Documents`, `Step6Confirm` → `Step7Confirm`
- [ ] 단계 정의 배열과 `page.tsx` 렌더 분기의 이중 진실 해소
  - 단계 수·라벨·검증은 배열에서 파생된다. 반면 무엇을 렌더할지는 `currentStep === N` 하드코딩이라 따로 논다. 타입도 테스트도 못 잡는 조용한 어긋남이라 단계를 넣을 때마다 두 곳을 맞춰야 한다
  - 단계 정의에 위치 무관 key를 넣고, 컴포넌트 매핑은 `page.tsx`에서 key 기준 `Record`로 둔다. key를 추가하면 매핑 누락이 컴파일 에러로 잡힌다
  - 단계 정의에 컴포넌트를 직접 넣는 방식은 데이터층이 UI를 import하게 되어 프렉탈 역방향 의존에 걸린다
- [ ] 진행 표시기 스토리의 단계 수 6 → 7, "확인" 단계 번호 갱신

### 4. 확인 단계

- [ ] 요약에 적은 질문 노출, 입력하지 않았으면 행 생략

### 5. 테스트

- [ ] E2E 데스크톱·모바일 스펙에 전할 말 단계 통과 반영
- [ ] 직접 진입 가드 테스트가 겨냥하는 단계 갱신

## API

- `POST /reports`의 `question`(nullable) 필드는 이미 명세에 있고 요청 스키마에도 반영돼 있다. 지금은 `null` 고정으로 보낸다. 이걸 입력값과 연결한다.
- 백엔드 변경·협의 불필요.

## 완료 조건

- [ ] 퍼널이 7단계로 동작하고 진행 표시가 PC `STEP 5 / 7`, 모바일 `5/7`로 보인다
- [ ] 질문을 적지 않아도 다음 단계로 넘어간다
- [ ] 500자를 넘겨 적을 수 없고 글자수가 실시간으로 반영된다
- [ ] 적은 질문이 분석 요청에 담겨 전달된다 (적지 않았으면 빈 값)
- [ ] 새로고침 후 임시저장을 복원하면 적어둔 질문이 남아 있다
- [ ] 예시 칩은 눌러도 아무 일도 일어나지 않는다
- [ ] 글자수 표시 옵션을 추가한 뒤에도 검수 의견·활동 분야 화면의 글자수 표시가 그대로다
- [ ] `pnpm typecheck` · lint · E2E 통과
- [ ] 모바일 RN WebView에서 레이아웃이 깨지지 않는다
